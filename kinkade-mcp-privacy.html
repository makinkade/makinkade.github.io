KinkadeMCP - Privacy Policy

Last updated: 28 August 2026

What this application is

KinkadeMCP is a personal, self-hosted tool. It runs as a local process on its owner's own computer and is used only by its owner. There is no hosted service, no server operated by anyone else, and no account to sign up for.

What data it accesses

With your permission, KinkadeMCP reads your Google Calendar using the https://www.googleapis.com/auth/calendar.readonly scope. This is read-only access: the application cannot create, change or delete any calendar entry. It requests no other Google data.

How that data is used

Calendar events matching a search are returned to the AI assistant session running on the same computer that asked for them, so that it can answer your question about your schedule. That is the application's only purpose. Event data is held in memory for the duration of the request and is not written to disk, logged, or retained afterwards.

What is stored

Only the Google OAuth tokens, kept on the local machine under the user's own profile directory, so that access does not have to be granted again on every run. No calendar content is stored.

Sharing

Your data is never sold, and it is never shared with any third party, apart from the AI assistant you are yourself conversing with when you ask it a question about your calendar.

Limited use

KinkadeMCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Withdrawing access

You can revoke this application's access at any time from your Google Account permissions page. You can also delete the locally cached token by running KinkadeMCP.exe revoke.

Contact

Questions about this policy can be sent to the address listed as the support contact on the application's Google consent screen.
